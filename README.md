# 🏠 Casaideas Perú — Prototipo Web Interactivo

Este es un prototipo funcional de una experiencia digital para Casaideas Perú. Está enfocado en la inspiración, exploración de productos, sostenibilidad y diseño personalizado del hogar. Desarrollado con HTML, CSS y JavaScript puro, sin frameworks.

## 🌟 Características principales

- 🎨 **Diseño interactivo y responsivo**
- 🛋️ **Arma tu espacio**: Filtrado de productos por estilo, color y temporada.
- ♻️ **Categoría eco-amigable** con información clara y opciones sostenibles.
- 🎁 **Planificador de regalos** por ocasión y presupuesto.
- 🛒 **Carrito de compras** con actualización dinámica.
- 💬 **Asistente virtual** (simulado) disponible 24/7.
- 👥 **Comunidad Casaideas**: galería UGC y blog de ideas.
- 📱 **Soporte móvil completo** y experiencia fluida.
